# 엔트리 링클 - LLNKKR

Less fluff. Pure function.

엔트리를 더 편리하게 사용할 수 있도록 만든 Chrome 확장 프로그램입니다.

## 주요 기능

- 다크 모드
- 엔트리 이야기 이미지 첨부
- 실시간 새 글 불러오기
- 작성 내용 24시간 자동 저장
- 안전한 마크다운
- 자동 더보기
- 홍보 글 숨김
- 이미지 스포일러

각 기능은 확장 프로그램 설정에서 켜고 끌 수 있습니다.
